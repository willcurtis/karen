# Karen AI

**Karen AI** is a comically judgmental terminal-based script designed for presentations, demos, or just mildly insulting your friends. She answers your questions with sass, sarcasm, and an ever-present air of superiority.

---

## 🧠 Features

- Terminal emulator feel with `Karen >` prompt  
- Colorized prompt and response output  
- Predefined question-answer pairs from a CSV file  
- Dramatic self-destruct mode with Matrix-style output  
- Flashing block cursor on shutdown  
- ASCII-art boot sequence and snarky boot message  

---

## 🚀 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/yourusername/karen-ai.git
cd karen-ai
```

### 2. Prepare the files

Make sure you have:

- `karen.py` — the main script  
- `responses.csv` — your list of predefined prompts and sarcastic responses  

### 3. Example `responses.csv`

```csv
prompt,response
hello,Hi there. I'm Karen. Try not to be annoying.
what is ai,AI is just software that doesn't like you.
self destruct,Matrix mode activated
```

### 4. Run Karen

```bash
python3 karen.py
```

Or make it executable:

```bash
chmod +x karen.py
./karen.py
```

---

## 🧩 Customization

- **Add more responses** by editing `responses.csv`. Prompts are case-insensitive.  
- **Change colors or prompt text** in `karen.py` by modifying the ANSI codes.  
- **Modify the ASCII art** or add animation effects for more dramatic flair.
